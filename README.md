# BODEN — Lånesystem

En enkel, iPad-anpassad demo för skolans bod.

## Flöde
1. Välj klass
2. Välj elev
3. Välj sak
4. Tryck "Låna ut"
5. Se och lämna tillbaka via "Aktiva lån"

## Demo
Appen innehåller påhittade klasser, elever och saker. Lån sparas lokalt i webbläsaren med `localStorage`.

## GitHub Pages
Lägg filerna `index.html`, `style.css` och `app.js` i ett GitHub-repo och slå på:
**Settings → Pages → Deploy from a branch → main → / (root)**

> För riktig skolmiljö bör nästa version få en gemensam databas/backend så att flera iPads ser samma lån.
