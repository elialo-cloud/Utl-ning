# BODEN — Lånesystem

En enkel, iPad-anpassad app för skolans bod.

## Flöde
1. Välj klass
2. Välj elev
3. Välj sak
4. Bekräfta utlåning
5. Tillbaka till klassvalet

## Lärarläge
PIN-skyddat lärarläge för aktiva lån, återlämning, saker, klasser och lånehistorik.

## Data
Demo-data och lån sparas lokalt i webbläsaren på den aktuella enheten.

## GitHub Pages
Appen är publicerad via GitHub Pages från `main` och `/ (root)`.

## V3
Den aktuella versionen är byggd för en gemensam iPad i boden där en klassvärd, lärare eller annan personal kan registrera lån snabbt.
